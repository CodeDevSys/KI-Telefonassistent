# KI-Telefonassistent

Cloud-basiertes MVP für einen KI-Telefonassistenten eines Friseursalons.

## Wichtige Dateien

```text
render.yaml
RENDER_SETUP.md
TWILIO_SETUP.md
DEPLOYMENT_CHECKLIST.md
salon-ai-assistant/
```

## Setup-Reihenfolge

1. `RENDER_SETUP.md` durcharbeiten.
2. `TWILIO_SETUP.md` durcharbeiten.
3. `DEPLOYMENT_CHECKLIST.md` abhaken.

Nach dem Deployment läuft das System vollständig auf Render.com. Es wird kein lokaler Laptop und kein ngrok benötigt.
